# Gestión de Gimnasio (Java) - Práctica de Depuración

Proyecto de programación en Java que simula la gestión de un gimnasio. El objetivo principal de esta práctica es el uso de herramientas de depuración (Debugging) en el IDE para identificar y corregir errores en tiempo de ejecución.

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java (JDK 17)
*   **IDE:** Apache NetBeans
*   **Herramientas de depuración:** Breakpoints, inspección de variables, ejecución paso a paso (Step Over / Step Into).

## 🎯 Funcionalidades y Conceptos Aplicados
*   **Lógica del programa:** Menú interactivo por consola para calcular precios de matrículas, aplicar ofertas y calcular importes totales.
*   **Depuración (Debugging):** 
    *   Establecimiento de **puntos de ruptura** (breakpoints) en la lectura de datos.
    *   Uso de la ventana de **variables** para inspeccionar el estado del programa.
    *   **Modificación de variables en tiempo de ejecución** mediante el inspector.
    *   Ejecución paso a paso para seguir el flujo del programa.

## 🚀 Cómo ejecutar el proyecto
1. Abre el proyecto en Apache NetBeans.
2. Ejecuta la clase principal (`Ejercicio01.java`) para probar el funcionamiento normal.
3. Para probar la depuración: pon un breakpoint en la línea de `teclado.next()`, ejecuta el proyecto en modo **Debug** (Ctrl+F5) y utiliza la ventana de variables para inspeccionar los valores.
